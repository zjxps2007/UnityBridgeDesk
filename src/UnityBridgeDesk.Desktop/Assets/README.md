# Cloud station 배경

`cloud-station.png`는 프로젝트의 파스텔 데스크톱 UI 시안을 위해 생성한 배경이다.

- 원본 크기: 1586 × 992
- 처리: WebP의 디코딩된 픽셀을 PNG로 저장. 그림의 구성·색상·해상도 수정 없음.
- 앱에 WPF 리소스로 포함하므로 시안 폴더나 외부 서버가 필요하지 않다.
- 구름 고양이 앱 아이콘은 `design/branding/desk-icon.xaml` 벡터 원본에서 `build/Build-Icon.ps1`로 생성한다. `desk.ico`는 16~256px의 9개 크기를 포함한다.
- 화면의 보조 아이콘은 Windows의 Segoe Fluent Icons와 WPF 벡터 선으로 표시한다. Windows 글꼴 파일을 저장소에 포함하지 않는다.

이 기록은 별도의 제3자 이미지 라이선스를 새로 부여한다는 의미가 아니다. 승인된 프로젝트 자산의 출처와 변환만 남긴다.

2026-09-17 내장 image_gen으로 `cloud-station-rose.png`와 `cloud-station-mint.png`를 추가했다. 기존 이미지의 파스텔 역 풍경을 기준으로 로즈·민트 색감과 둥근/길게 흐르는 구름 형태를 편집했다. 두 파일 모두 1586 × 992 PNG 원본 출력이며 앱에 내장한다. [프롬프트와 최종 자산 기록](../../../docs/THEME-ASSETS.md)을 함께 보관한다.
