# UnityBridge Desk

<img src="design/branding/desk-icon.png" width="96" alt="구름 고양이 마스코트" />

**UnityBridge 설치·관리, AI 작업, 버전 비교를 한곳에서 사용하는 Windows 데스크톱 앱입니다.**

[UnityBridge](https://github.com/zjxps2007/UnityBridge)를 위한 별도 도구로, 세 기능을 독립적으로 사용합니다. 파스텔 테마와 고정 탭 작업실을 제공하며 브라우저나 별도 UI 서버가 필요하지 않습니다.

[사용 가이드](docs/USAGE.md) · [벤치 측정 방식](docs/BENCHMARKS.md) · [개발·빌드](docs/DEVELOPMENT.md) · [GitHub 업로드](docs/PUBLISHING.md)

## 주요 기능

| 기능 | 할 수 있는 일 |
|---|---|
| 설치·관리 | 프로젝트에 Connector 적용, 백업과 연결 확인 |
| AI 작업 | 앱에서 자연어 지시를 입력하고 Codex CLI로 작업 실행 |
| 벤치마크 | 같은 작업을 여러 Bridge 버전에 수행하고 결과 비교 |
| 빠른 설정 | 최근 프로젝트·기본 설치 위치·이전 경로 탐색과 선택 |
| 결과 확인 | 단계별 진행, 성공·실패 기록, JSON·CSV 내보내기 |

고정 명령과 AI 제작 벤치를 각각 켜거나 함께 실행할 수 있습니다. 고정 명령만 사용하면 AI 계정과 모델이 필요하지 않습니다.

## 실행하기

실행용 ZIP을 받았다면 **압축을 모두 풀고 → UnityBridge Desk 실행.exe**를 실행하세요. `app/` 폴더와 실행 파일을 함께 보관합니다. ZIP에는 .NET 런타임이 포함되어 있습니다.

소스를 받은 경우에는 아래의 [소스에서 빌드](#소스에서-빌드)를 사용합니다. GitHub의 Source code ZIP에는 실행 파일이 들어 있지 않습니다.

별도로 준비할 항목:

- Windows x64와 Unity 프로젝트, 프로젝트 버전에 맞는 Unity Editor
- UnityBridge의 Windows CLI와 Connector 폴더
- AI 사용 시 Codex CLI, 모델 ID와 파일 인증이 설정된 홈

## 처음 사용할 때

1. **보관함 → 빠른 설정**에서 찾아 둔 프로젝트를 선택합니다.
2. 사용할 Bridge 조합을 등록·선택합니다. 목록에 없으면 **다른 위치의 폴더 추가**로 한 번 지정합니다.
3. **설치·관리 / AI 작업 / 벤치마크** 중 사용할 도구를 엽니다.
4. 자동으로 찾은 Editor와 실행 조건을 확인하고 **구성 확인**을 누릅니다.
5. 검토 후 표시되는 **설치 시작 / AI 작업 시작 / N개 시행 시작**을 누릅니다.

기억한 위치는 다른 도구에서도 재사용합니다. 이미 지정한 유효한 경로는 유지하고, 찾지 못한 항목은 직접 고를 수 있습니다. 현재 도구의 입력과 결과는 탭을 바꿔도 유지됩니다.

벤치는 완료 후 **3 결과**를 자동으로 엽니다. 성공·실패 수를 먼저 보고 같은 조건의 시간과 표본 수를 비교하세요. 상세 흐름과 문제 해결은 [사용 가이드](docs/USAGE.md)에 있습니다.

## 벤치마크 개요

| 방식 | 실험 |
|---|---|
| 고정 명령 F01~F05 | 응답 시간, 명령 분할, 응답 크기, 코드 변경 후 복귀, Play/Stop |
| AI 제작 A01~A03 | 낙하 장면, 프리팹 예외와 변경 전파, 물리 제어 도구 |

각 시행은 새 프로젝트 복제본과 Unity 프로세스에서 수행합니다. 준비·작업·검증·정리 시간을 구분하며 성공 여부와 독립 시행 수를 함께 표시합니다.

**F01의 첫 호출은 Unity 기동·컴파일이 끝난 뒤의 첫 명령입니다.** 프로젝트 생성부터 걸린 시간이 아닙니다. 현재 실험 명세는 `draft-v1` 예비 시험용이며 종합 승자나 점수를 자동으로 만들지 않습니다. [측정 범위와 결과 해석](docs/BENCHMARKS.md)을 확인하세요.

## 소스에서 빌드

Windows, PowerShell 7, `global.json`의 **.NET SDK 10.0.400**이 필요합니다. 저장소 루트에서 실행합니다.

```powershell
pwsh -File ./build/Verify.ps1 -Restore
pwsh -File ./build/StartDesk.ps1
```

자동 검사는 합성 자료를 사용하며 사용자 Unity 프로젝트와 유료 AI 서비스를 실행하지 않습니다. 실행용 ZIP 제작에는 MinGW-w64의 `gcc.exe`와 `windres.exe`가 추가로 필요합니다. [개발 가이드](docs/DEVELOPMENT.md)에 폴더 구조와 패키징 명령이 있습니다.

## 현재 상태

- Windows 시험 배포 단계입니다. 최근 로컬 자동 검사 **138개**가 통과했습니다.
- 실제 Unity 복제본에서 고정 명령과 통합 흐름을 시험했습니다. 공개 소스에는 개인 경로가 포함된 원시 시험 기록을 넣지 않습니다.
- 실제 생성형 AI 서비스 연결 시험은 아직 수행하지 않았습니다.
- 공개 서명, 설치 프로그램, 자동 업데이트는 제공하지 않습니다.
- OS 캐시·발열·네트워크·외부 AI 서비스 상태까지 완전히 고립하는 벤치는 아닙니다.

설정·초안·실행 기록은 기본적으로 `%LOCALAPPDATA%/UnityBridgeDesk`에 저장합니다. 인증 파일과 개인 실행 기록은 소스나 실행용 배포본에 포함하지 않습니다.
