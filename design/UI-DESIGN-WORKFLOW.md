# Desk 디자인 작업 기준

2026-09-19 · 사용자가 요청한 이후 UI 작업의 공통 기준이다. 이번 문서 추가로 앱 화면이나 기능을 변경하지 않았다.

## 목표와 우선순위

Desk의 실험·조건·버전·시행·측정 결과를 빠르게 이해하고 조작할 수 있는 화면을 만든다. 작업마다 디자인 스킬과 관련 MD를 실제로 읽고, 서로 다른 역할의 지침을 하나의 설계로 조합한다. 디자인 출처를 늘리는 것만으로 품질이 확보되지는 않는다. 각 선택이 Desk의 데이터와 작업에 필요한 이유를 설명하고 실제 화면에서 검토한다.

최신 사용자 요청, 현재 제품의 동작과 측정 의미, 프로젝트의 현재 문서, 외부 참고 지침 순으로 판단한다. 외부 문서의 예제 색상·레이아웃·개발 기술을 사용자의 요구보다 우선하지 않는다.

## 유지할 정체성

- 정보가 중심이다. 파스텔 바탕과 연보라 강조색, 로즈·민트 테마를 유지한다.
- 구름 고양이는 작은 보조 캐릭터이다. 분명한 실루엣과 반응성을 유지하며 글로우를 추가하지 않는다.
- 좌측 탐색과 중앙 작업면, 준비·진행·결과 흐름을 유지한다. 큰 시계와 우측 위젯을 다시 중심 요소로 만들지 않는다.
- 떠다니거나 끌어 이동하는 도구 패널을 다시 도입하지 않는다.
- 세로 그래프의 버전 순서와 색상 대응을 일관되게 유지한다. 실패·누락과 0ms를 구분한다.
- 움직임은 사용자의 입력과 변화 이해에 도움을 준다. 기존 움직임 끄기와 벤치 실행 중 정지 조건을 보존한다.

웹의 CSS·ARIA와 모바일의 터치 단위는 WPF에 그대로 옮기지 않는다. WPF의 DIP, 키보드 포커스, AutomationProperties, 목록 가상화와 Windows 설정에 맞춰 적용한다. 고정된 폰트 이름이나 유행하는 스타일을 선택하는 것 자체를 독창성으로 취급하지 않는다.

## 반복되는 템플릿 표현을 검토할 기준

다음 표현을 기본값으로 반복하지 않는다. 필요한 경우에는 정보나 조작상의 이유가 있어야 한다.

- 중요도와 관계없이 내용을 동일한 둥근 카드로 나누는 배치.
- 비교 대상과 단위는 작게 숨기고 숫자만 크게 강조하는 요약.
- 장식용 그라데이션·그림자·배지·아이콘·영문 소제목의 반복.
- 단계가 아닌 항목에 붙이는 번호와 모든 버튼에 붙이는 화살표.
- 모든 화면에 같은 여백·같은 카드 수·같은 가운데 정렬을 적용하는 구성.
- 모든 요소가 떠오르거나 흔들려 조작의 우선순위가 흐려지는 반응.
- 독특하게 보이기 위해 일반적인 버튼·선택·스크롤 동작을 바꾸는 구성.

이는 특정 색이나 둥근 모서리를 금지한다는 뜻이 아니다. 사용자 지정 연보라를 피하거나 다른 유행 스타일로 일괄 교체하지 않는다. 준비는 설정의 순서, 진행은 현재 작업과 종료 상태, 결과는 비교와 근거가 각 화면의 구조를 결정한다.

## 작업 순서

1. 현재 화면과 실제 코드를 보고 불편한 동작을 구체적으로 적는다. 이미 있는 기능을 새 제안처럼 추가하지 않는다.
2. 작업에 맞는 스킬·MD를 읽고 각각에서 적용할 원칙과 적용하지 않을 예제를 정한다.
3. 구현 전 읽기 순서, 배치, 글자 역할, 색의 역할, 조작 피드백을 짧게 정리한다. 큰 개편은 간단한 배치안으로 비교한다. 이 자체가 새로운 사용자 승인 절차는 아니다.
4. Desk의 실제 데이터 형식으로 검토한다. 긴 버전명, 여러 비교 대상, 실패, 결과 없음, 유효 시행 부족도 포함한다. 가상 수치로 시안을 만들면 예시라고 표시한다.
5. 승인된 범위에서 구현하고 실제 렌더링 화면을 확인한다. 빌드 성공만으로 디자인 검토를 끝내지 않는다.
6. 수정 범위에 맞게 작은 창·확대 배율·긴 목록·키보드·스크롤·선택 복원·빠른 반복 조작을 확인한다. 실험 중 장식 효과의 정지 조건도 해당 변경에 영향을 받으면 확인한다.
7. 사용한 자료, 채택한 판단, 확인한 화면과 남은 한계를 기록한다. 이전 단계의 제안을 이미 구현된 기능으로 문서화하지 않는다.

## 변경 기록에 남길 항목

- 해결하려는 사용자 동작과 현재 문제.
- 참고한 스킬·MD 및 실제 확인 날짜.
- 각 자료에서 채택한 원칙과 Desk에 맞춰 제외·수정한 내용.
- 기존 화면과 달라지는 읽기 순서·조작 횟수·선택 유지 방식.
- 실제 화면 확인 결과와 기능·측정 의미 보존 여부.
