# 화면 반응과 아샤

2026-09-20: 두 캐릭터의 가감속, 자세 연결, 착지 회복과 대기 동작을 개선했다. [현재 캐릭터 모션](CHARACTER-MOTION.md)

> 2026-09-20 갱신: 기존 고양이는 **아라**, 새 여우는 **아샤**이다. 설정 → 캐릭터에서 각각 표시·탐색·활동량을 선택한다. 아래 표의 기존 고양이 동작은 아라에 이어지며, 여우의 동작과 변경된 자유 낙하는 [현재 캐릭터 안내](CHARACTERS.md)를 따른다. 설정·벤치·비활성화·움직임 끄기의 정지 조건은 두 캐릭터에 함께 적용한다.

2026-09-19 · 반복되는 반응을 줄인 현재 동작 기준이다.

화면은 정보가 제자리에 머물도록 구성한다. **설정** 팝업에서 움직임 전체를 끄거나, 아샤 표시·산책·활동량을 각각 바꿀 수 있다. 기존 선택은 유지하고 다음 실행에도 복원한다.

## 화면 전환

| 조작 | 현재 표현 |
|---|---|
| 준비·진행·결과 선택 | 선택 밑줄만 160ms 동안 이동한다. 본문은 위치를 고정한 채 96%에서 100%로 120ms 동안 짧게 전환한다. 왼쪽 목록은 함께 움직이지 않는다. |
| 실행 기록 열기 | 해당 작업면에만 같은 짧은 전환을 적용한다. 같은 화면을 다시 누르면 반복하지 않는다. |
| 설정 열기 | 현재 작업 위에 팝업을 즉시 표시한다. 설정 분류는 이동 효과 없이 전환하며 아샤를 잠시 숨기고 정지한다. |
| 결과 보기·조건·시행 선택 | 내용과 실제 수치를 즉시 바꾼다. 읽는 동안 본문 이동이나 반복 등장 효과를 넣지 않는다. |
| 버튼·목록·메뉴 항목 | 옅은 배경으로 포인터·눌림·선택 상태를 바로 표시한다. 버튼과 글자를 축소하거나 이동하지 않는다. |
| 목록 접기·펼치기, 드롭다운, 펼침 영역 | 배치와 화살표를 즉시 바꾼다. 여러 영역이 동시에 움직이지 않는다. |
| 입력·검색·스크롤 | 기본 WPF 동작을 유지한다. 키보드 포커스는 바로 표시한다. |

화면 전환은 입력 처리를 기다리게 하지 않는다. 빠른 재선택은 진행 중인 효과를 대체하며 대기열을 만들지 않는다. 그래프 막대의 높이와 진행 숫자를 장식적으로 보간하지 않는다. 배경은 정지 이미지이다.

설정 팝업은 작업 탭·실행 기록을 그대로 둔 채 열린다. 닫으면 원래 조작 위치로 포커스를 돌려준다. 실행 기록의 검색과 선택을 유지한다. 기록을 읽는 중 다른 페이지로 이동하거나 다른 기록을 선택하면 늦게 끝난 읽기가 현재 화면을 바꾸지 않는다.

## 아샤의 반응

| 상태·입력 | 현재 동작 |
|---|---|
| 앱으로 돌아옴 | 0.8~1.4초 후 발판 탐색을 시작한다. |
| 그래프 근처 | 가능한 낮은 막대부터 올라가 높은 막대로 점프하고 여러 막대를 탐색한다. 놀이당 5~9회 도착하며 다음 놀이까지 18~42초를 무작위로 고른다. 착지 후 짧은 대기와 가끔 긴 살피기를 섞는다. [상세 로직](ASHA-CHART-PLAY.md) |
| 자율 행동 | 실제로 갈 수 있는 구역 중 덜 방문한 곳을 우선하며 좌우로도 탐색한다. 최근에 간 자리 주변을 감점한다. 긴 휴식·자동 수면 없이 이동을 이어가며 도착 후 간격은 얌전함 0.9~1.6초, 보통 0.4~0.8초, 활발함 0.25~0.45초이다. |
| 뛰어내리기 | 발판 위의 안전한 출발 자리까지 걷고 아래를 살핀다. 좁으면 제자리에서 살핀다. 낙차가 클수록 몸을 더 모으며 착지도 더 깊고 길어진다. |
| 귀·시선·꼬리 | 목적지를 살피는 시선과 귀, 이동 중 균형을 잡는 꼬리의 작은 변화를 기존 그림에 적용한다. 정지하면 변형도 해제한다. |
| 대기 · idle | 상체만 작게 호흡하고, 충분히 오래 머물 때 귀·꼬리·주변 살피기를 하나씩 선택한다. 좁은 발판에서는 발을 모으고 넓은 곳에서는 작은 기지개도 선택한다. 반응 사이에는 4~8초 간격을 두며 산책 출발은 미루지 않는다. |
| 대기로 돌아옴 | 현재 자세에서 약 180ms 동안 부드럽게 풀린다. 마지막 방향을 유지하며 몸 전체를 반복해서 확대·축소하지 않는다. |
| 이어지는 걷기 | 발걸음을 실제 이동 거리에 맞춘다. 출발·정지에 최대 0.22초의 속도 변화를 적용하고 같은 방향의 중간 발판에서는 멈추지 않는다. |
| 방향 전환 | 약 0.34초 동안 눈·고개·몸 순서로 돌아본다. 대기·살피기·정지 때 바라보는 방향을 유지한다. |
| 화면 복귀 | 화면·발판별 마지막 자리를 검증해 복귀한다. 새 배치의 안전한 자리에서 약 140ms 동안 나타난다. |
| 올라가기 어려운 곳 | 갈 수 있는 경로가 없으면 앞발을 뻗는다. 같은 반응에는 45초 간격을 둔다. |
| 입력·버튼 조작·스크롤 | 걷기는 멈추며 공중에서는 착지를 마친다. 마지막 입력부터 3초간 다음 탐색을 미룬다. 경로가 사라지면 안전한 발판으로 보정한다. |
| 포인터를 아샤 위에 잠시 둠 | 약 650ms 머물면 바라본다. 스쳐 지나가는 포인터는 무시하고, 같은 반응은 최소 15초 간격을 둔다. |
| 클릭 또는 Enter·Space | 힐끔 보기 → 앞발 장난 → 시큰둥한 반응으로 달라진다. 짧은 중복 입력을 제한하고 5초 이상 쉬면 첫 반응부터 시작한다. |
| 끌어 놓기·우클릭 | 빈 곳에 놓으면 아래로 가속하며 떨어져 실제 발판에 착지한 뒤 몸을 정돈한다. 안전한 낙하가 불가능하면 다른 실제 발판으로 복귀한다. 우클릭에서 반응 보기, 처음 자리로, 탐색/쉬기, 숨기기를 사용할 수 있다. [낙하 규칙](ASHA-FALLING.md) |

버튼의 윗면과 화면에 실제로 보이는 텍스트 줄을 개별 발판으로 인식한다. 큰 구분선은 이동을 이어주는 보조 발판으로 사용한다. 몸이 다른 줄·버튼·그래프를 가리지 않는 착지 자리와 경로를 선택하며 공중을 바닥으로 취급하지 않는다. 좁은 줄 사이에는 억지로 들어가지 않는다. 앱 전체의 절제된 반응은 유지한다. [버튼·줄 인식](ASHA-FINE-SURFACES.md) · [아샤의 발판·경로·프레임 구조](ASHA.md)

## 정지와 검증

벤치 준비부터 측정·정리 종료까지 아샤를 숨기고 프레임·이동·행동 판단과 장식 전환을 정지한다. 앱 비활성화·최소화, 숨김, Windows 애니메이션 비활성화, 앱 종료도 정지 조건이다. 진행 상태와 오류 표시는 계속 갱신한다. 움직임을 끄면 선택 밑줄도 즉시 최종 위치로 맞춘다.

실제 WPF 검사에서 빠른 탭 재선택, 본문·버튼 위치 고정, 효과 종료·정지, 스크롤 중 아샤 정지, 걷기 네 프레임과 숨김·복귀를 확인한다. 벤치 측정 구간·명령·집계·성공 판정은 변경하지 않는다. 테스트와 화면 캡처에는 합성 입력과 기존 기록을 사용하며 새 Unity·유료 AI 실험을 실행하지 않는다.
