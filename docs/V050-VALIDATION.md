# v0.5.0 검증 기록

2026-09-21. v0.4.0 이후 UI·UX·아라·아샤·측정 방법론 후속 개선을 통합한 배포다. 이번 버전 번호 변경으로 명령·타이머·성공 판정·통계 수식을 추가 변경하지 않는다.

## 검사 범위

`build/Verify.ps1`로 빌드와 Core·Infrastructure·Desktop·Companion의 전체 회귀 검사를 수행한다. Desktop 검사는 실제 WPF 렌더링, 작은 창·확대 배율, 설정·선택 복원, 캐릭터 발판·낙하, 비교 구간·순서 그래프를 포함한다. 통계 검사는 t 분위수·Fieller 역산·작은 표본·모의실험·원본 보존을 포함한다.

`build/Verify-Package.ps1`은 실행기·Desktop·Worker·명세가 모두 0.5.0인지, 실행용 ZIP과 모든 배포 파일의 해시가 일치하는지 검사한다. 한글 경로로 옮긴 실행기의 작업 폴더와 따옴표·빈 인수 전달은 합성 실행 파일로 확인한다.

Desk 전용 소스 묶음은 `build/Export-Source.ps1 -DeskOnly`로 생성한다. 로컬 결과·로그·캐시·실행 파일과 독립 앱 리틀 모델 엔진 소스는 포함하지 않는다. `.gitignore`·`.github` 등 숨김 파일과 ZIP 내부 해시를 함께 확인한다.

## 이번 통합의 한계

이번에는 실제 Unity·VM·유료 AI를 실행하지 않는다. 이전 실제 연동 결과는 [v0.4.0 검증 기록](V040-VALIDATION.md)과 각 도구 비교 문서의 당시 조건에 해당한다. 합성 검사를 실측 성능 개선이나 모든 분포의 신뢰구간 보장으로 해석하지 않는다.

## 확인 결과

- `build/Verify.ps1`: 빌드 경고·오류 0개. **Core 38 + Infrastructure 194 + Desktop 76 + Companion 13 = 321개 통과**. 테스트 호스트 종료 과정의 처리되지 않은 예외도 검사했다.
- 버전 변경 후 빌드된 Desk·Worker의 ProductVersion은 **0.5.0**이다. 별도 리틀 모델 엔진의 ProductVersion은 **0.1.0**으로 유지된다.
- 앱 창 제목은 어셈블리 버전에서, 실행기와 배포 명세는 `Directory.Build.props`에서 버전을 읽는다. 수동으로 다른 번호를 표시하는 별도 경로를 추가하지 않았다.
- 릴리스·현재 사용법·개발·업로드 안내는 v0.5.0을 사용한다. v0.4.0 릴리스 설명과 당시 검증 기록은 과거 기록으로 보존한다.

실행용 묶음의 최종 파일·ZIP 검증은 위의 `Verify-Package.ps1` 절차를 사용하며, 전달 파일에는 SHA-256 목록을 별도로 제공한다.
