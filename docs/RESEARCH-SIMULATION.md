# 수식 민감도 모의실험

앱 밖에서 Python 3.10 이상 표준 라이브러리로 실행한다. 새 결과 폴더를 지정하며 기존 자료를 덮어쓰지 않는다.

```powershell
python tools/research/simulate_intervals.py --output simulation-new --replications 1000 --pairs 30 --seed 20260921
```

`00_모의실험요약.txt`, 계획과 코드 해시의 `plan.json`, 수치의 `results.json`을 생성한다. Unity·CLI·유료 API를 호출하지 않으며 벤치 실행과 동시에 수행하지 않는다.

## ADEMP 구성

- 목표: 상위 시행을 독립으로 보는 현재 쌍 t/Fieller 수식이 분포·상관·선택적 실패에 얼마나 민감한지 조사한다.
- 생성: 평균 100의 로그정규·감마, 5% 확률의 긴 꼬리 혼합, 두 대상의 분산 차이, 정상 AR(1) 상관 0.75, 5개 세션 군집, B가 130을 넘으면 쌍에서 빠지는 시간 의존 실패를 사용한다. 코드의 생성식·시드를 계획과 함께 고정한다.
- 추정 대상: 모집단 산술평균의 비율 B/A이다. 기본 참값은 1, 알려진 차이는 0.9이다. 시간 의존 실패는 성공쌍 조건부 참값을 절단 로그정규 분포에서 계산하며 전체 요청의 참값과 구분한다.
- 방법: Desk의 쌍 Fieller 수식을 별도 Python으로 구현한다. 시나리오 첫 자료는 독립 대조식 역산 검산기와 대조한다. 실제 C# 프로그램 전체를 모의실험마다 실행한 검사는 아니다. C# 계산 일치는 별도의 앱 산출물 검산으로 확인한다.
- 평가: 유한 구간 제공 수, 전체 반복 중 올바른 유한 구간 비율, 유한 구간 조건부 포함률, 폭·편향·잘못된 방향 판정과 Monte Carlo 표준오차를 기록한다. 구간 미제공을 분모에서 몰래 제외하지 않는다. 이 표는 불안정한 Fieller의 전체 비연결 신뢰집합을 평가하는 구현은 아니다.

[Morris·White·Crowther의 ADEMP 연구](https://discovery.ucl.ac.uk/id/eprint/10066118/1/2019%20-%20Morris%20-%20simulation%20studies%20tutorial%20-%20stat%20med.pdf)의 설계·추정 대상·평가 지표 구분을 참고했다. 비율 추정의 성질은 [Franz의 연구 원고](https://arxiv.org/abs/0710.2024)도 참고한다. 이 원고를 Unity 실측이나 해당 도구의 인증으로 취급하지 않는다.

## 2026-09-21 실행 관찰

각 시나리오 1,000회, 계획 30쌍, 시드 20260921로 총 8,000개 자료를 생성했다. 아래는 전체 반복 중 참값을 담은 유한 구간의 비율이다. 이번 자료에서는 유한 구간 미제공이 없었다.

| 생성 조건 | 올바른 유한 구간 | Monte Carlo SE |
|---|---:|---:|
| 로그정규 | 95.7% | 0.64%p |
| 알려진 차이 0.9 | 94.6% | 0.71%p |
| 감마 | 95.3% | 0.67%p |
| 분산 차이 | 94.6% | 0.71%p |
| 긴 꼬리 혼합 | 97.5% | 0.49%p |
| AR(1) 상관 | 52.2% | 1.58%p |
| 세션 군집 | 49.5% | 1.58%p |
| 시간 의존 실패, 성공쌍 조건부 참값 | 95.4% | 0.66%p |

상관·세션 군집에서는 독립 시행 가정이 어긋나 구간의 성질이 크게 나빠졌다. 이는 세션 구분과 순서 진단을 생략하면 안 된다는 모의 사례이며 실제 Unity의 포함률 추정은 아니다. 성공쌍 분석이 잘 맞더라도 전체 요청 평균을 추정한 것은 아니다.

실제 예비 분포에 맞춘 생성, 더 많은 반복, 여러 표본 수·효과 크기, 쌍·블록·세션 부트스트랩, 다중 비교, 파워·표본 수 배분은 후속 검증으로 남는다. 이 결과를 근거로 현재 구간이 모든 분포에서 검증됐다고 표현하지 않는다.
