## 정보와 조작

결과는 관찰 평균 → 95% 구간·해석 → 필요할 때 분산·비용·다음 실험 순서로 읽는다. 상세 수식과 비용 설명은 펼침 안에 두며 상단에 새 카드를 만들지 않는다. 호출 순서 그래프는 실제 시행 상세에서, 시행 순서 그래프는 비교 근거 안에서 읽는다. 두 그래프 모두 애니메이션이나 자동 정렬을 하지 않는다.

준비의 예비 설정은 숫자 세 개를 채우는 동작이다. 다음 실험 준비는 기존 기록의 설정 재사용 경로를 사용하되 반복 수를 제안값으로 바꾼다. 두 기능 모두 실험을 자동 실행하지 않는다. 현재 실행·원본 기록·다른 조건의 보기 위치는 변경하지 않는다. 외부 통계 라이브러리·상시 분석 타이머를 추가하지 않는다.

## 검증

합성 측정 자료임을 명시한 테스트 실행에서 960×600, 1440×850과 100·150·200% 렌더링을 확인했다. 구간·표본 부족·미완료 상태, 다음 실험 버튼의 조건, 순서 그래프, 작은 화면 스크롤을 검사했다. 실제 Unity 측정과 성능 검증은 별개다.

2026-09-21 최종 `build/Verify.ps1`은 경고·오류 0개, Core 38 + Infrastructure 194 + Desktop 76 + Companion 13 = **321개 통과**로 끝났다. Companion 소스는 변경하지 않았으며 전체 회귀 검사에만 포함했다. 테스트 호스트 종료 중 처리되지 않은 예외도 검사했다. 이전 보고서 형식 4·5·6·9에서 새 형식 10으로 별도 사본을 만드는 검사, 기존 JSON 보존 검사, t 분위수와 Fieller 역산, 1,000개 합성 정규 실험의 구간 포함률 검사도 통과했다. 실제 Unity 성능 결과를 새로 생성하지 않았다.
