# UnityBridge Desk v0.3.2 — 결과 요약과 Excel 분석

JSON·CSV를 먼저 열어야 했던 결과 확인 흐름을 개선했습니다. 결과 탭의 짧은 메모에서 상태와 건수를 확인하고, 조건별 시간·버전 차이·선택 시행의 오류를 순서대로 볼 수 있습니다.

- 결과 버튼을 요약 메모(TXT 열기·메모 복사), 분석 Excel 열기, 자료 폴더(보고서·원본 로그)로 묶었습니다. 시행별 로그는 선택한 시행 옆에, 이전 기록과 테마는 앱 관리 메뉴에 있습니다.
- TXT와 복사 메모에 어떤 조건에서 어느 버전이 평균 몇 ms, 몇 % 빨랐는지 문장으로 정리합니다. 공동 유효 블록만 비교하고, 실패·비교 불가·작은 차이를 구분합니다.
- TXT 요약, 네 시트의 XLSX, 실패 내역을 자동 생성합니다. 과거 기록도 재실험 없이 보고서로 만들 수 있습니다.
- 실패·중단·정리 실패·미수행을 구분하고, 조건·버전·상태별 필터를 제공합니다.
- 같은 블록의 공동 유효 시행만 비교하며, 시행 대표시간과 개별 호출을 분리합니다.
- 원본 JSON·CSV·로그와 사용자가 편집한 보고서를 보존합니다.
- 보고서 작성은 측정 종료 뒤 수행하고, 저장 오류는 벤치 결과 상태와 구분합니다.

측정 명령과 시간 경계, 로컬 실행 방식은 유지합니다. 별도 설명 메모 탭은 추가하지 않았습니다.

검증: 자동 검사 190개(보고서·문장형 비교 검사 12개 포함), 작은 창의 WPF 배치·필터 확인. 저장된 실제 48개 시행은 성공 46·실패 2, 공동 유효 30/32블록으로 집계되며 원본 해시가 유지됨을 확인했습니다. 새 Unity 성능 측정은 수행하지 않았습니다.

실행 파일: 실행용 ZIP 전체를 압축 해제한 뒤 **UnityBridge Desk 실행.exe**를 엽니다. 옆의 `app` 폴더도 함께 필요합니다.
