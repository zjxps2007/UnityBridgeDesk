## Summary

feat: v0.3.0 속도 벤치 전용 버전 출시

## Description

UnityBridge Desk의 기능을 릴리스별 고정 명령 속도 비교로 축소하고, VM 없이 설치된 Unity에서 실행하도록 전환했습니다.

- 일반 설치·관리, AI 작업, VM 관리 진입점을 기본 앱에서 제외
- Unity 자동 탐색, 정식·RC CLI 및 Connector 자동 준비와 해시 확인
- 시행별 새 프로젝트·임시 경로·UPM 캐시와 시험 프로세스 정리
- 첫 호출·명령 분할·응답 크기 실험, 응답 검증 및 JSON·CSV 결과
- 파스텔 테마·큰 시계·탭 유지, 하단 시작 버튼과 설정 초기화
- README에 벤치 설계의 근거·측정 경계·공유 환경의 한계 추가
- 앱·실행기·배포 파일을 v0.3.0으로 통일하고 릴리스 문서 정리

검증: 자동 검사 170개 통과, Unity 6000.3.23f1에서 실제 18개 시행 성공 및 중단 정리 확인. Windows 공용 캐시·사용자 설정은 공유하며 결과는 예비 기술 통계입니다.
