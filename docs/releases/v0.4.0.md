# UnityBridge Desk v0.4.0 · exec·부하 안정성·그래프

UnityBridge 버전별 속도 비교에 exec 실행 경로, 고부하·고밀도 명령 시험과 결과 그래프를 추가했습니다.

## 공식 Unity CLI + Pipeline 비교

**준비 → 비교 대상 → 공식 Unity CLI + Pipeline 함께 비교**를 켜고 UnityBridge 릴리스를 한 개 이상 선택한 뒤 **벤치 시작**을 누릅니다. 필요한 공식 도구 파일도 자동 준비하며 기존 진행·중단·결과 화면에서 비교를 마칩니다. 버전 지정은 선택 사항이고, 선택 저장과 결과에서 실제 사용 버전으로 설정 복원을 지원합니다. 같은 작업을 새 프로젝트에서 실행해 공통 기준으로 측정·검증합니다. F01~F04와 공통 S01, 기준 대상 지정, TXT·Excel·SVG 보고서를 지원하며 설치·활성화된 Unity 6가 필요합니다. [앱 사용법과 비교 범위](../OFFICIAL-UNITY-COMPARISON.md)를 참고하세요.

공식 도구 파일은 Desk 전용 하위 임시 폴더에 준비하고 벤치 종료·오류·취소 시 다운로드 원본까지 삭제합니다. 미리 준비만 하고 앱을 닫아도 정리하며, 다음 벤치는 새로 내려받습니다. 공식 CLI의 설정·캐시용 경로도 시행별로 분리하고 삭제 확인 여부를 결과에 표시합니다. 시스템 전체 캐시를 초기화하는 방식은 아닙니다.

임시 설치·정리 변경 이후 자동 검사 239개를 통과했습니다. 실제 연동 결과와 개발 중 발견·수정한 오류는 [검증 기록](../V040-VALIDATION.md)에 구분해 기록합니다. 최소 반복의 연동 확인을 성능 우열의 근거로 사용하지 않습니다.

## 결과 화면·준비 편의 개선

- 정보 중심의 넓은 작업면으로 개편했습니다. 우측 위젯 영역을 없애고 파스텔 색면·좌측 탐색·중앙 결과를 사용합니다. 시계는 상단으로 줄여 옮겼고, 마스코트는 좌측 하단의 숨길 수 있는 보조 요소입니다.
- 탭·버튼·메뉴 반응을 부드럽게 다듬고, 캐릭터를 큰 머리와 작은 몸의 구름 고양이로 바꿨습니다. 눈 깜빡임·시선 이동·꼬리와 귀 움직임·클릭 반응을 지원합니다. 설정에서 움직임을 끌 수 있으며 벤치 중, 앱 비활성화·최소화 때 자동 정지합니다. [동작 미리보기](../MOTION.md)
- 두 대상이 모두 유효한 블록의 평균 시간 차이와 통계 포함·제외 횟수를 먼저 보여줍니다. 한 블록만 비교하면 반복 변동 미확인을 표시합니다. 여러 후보를 합쳐 임의의 우승자를 만들지 않습니다. 내보내기는 한 메뉴로 모았으며 준비 화면은 창 폭에 따라 두 열 또는 한 열로 배치합니다.
- 좌측은 준비 목차 / 진행 시행 / 결과 실험·조건·시행 탐색으로 나눴습니다. 원래 시행 번호 검색, 버전·상태 필터, 현재 시행으로 돌아가기를 제공합니다. 진행 중 사용자가 읽던 시행은 유지하고, 시행 표는 필요할 때 펼칩니다.
- 세로 그래프에서 평균·버전·유효 횟수를 확인하고 막대를 눌러 해당 시행으로 이동합니다. 조건별 시간, 기준 대비 비교, 시행 상세를 별도 화면으로 전환합니다.
- ‘첫 명령 완료 시간’과 ‘반복 명령 평균 시간’을 구분하고 사전 실행·측정 명령·프로젝트 실험 횟수와 시간 단위를 표시합니다.
- 기준 버전 직접 선택, 입력 범위·준비 상태 안내, 실행 기록 검색·설정 재사용·현재 조건 그래프 저장을 지원합니다.
- v0.1.3의 미지원 CLI 옵션 전달 문제를 수정했습니다. 실행 전 도움말로 기능을 확인하고 호환성 오류를 명령 성능 실패와 구분합니다.
- 작은 창에서는 좌측 목록을 접고 그래프 높이를 조절합니다. 목록은 Alt+0으로 펼치고 접습니다. 내보내기와 설정 재사용은 중앙 상단에 유지합니다. 전체 자동 검사 247개를 통과했습니다. [새 화면 안내와 검증](../UI-NAVIGATION.md)

## 추가한 기능

- **F04 exec 시험**: 동일 C# 파일의 첫 실행과 준비 후 실행을 비교합니다. CLI·전달·C# 컴파일·실행을 포함하고 반환값·요청 식별자·대상을 검증합니다.
- **S01 부하 시험**: 명령당 총 요청 수와 최대 동시 요청 수를 지정합니다. 작은 요청, 1 MiB 응답, 오브젝트 1,000개 생성·제거, exec, Editor 상태 조회를 기본으로 제공합니다. 다른 UnityBridge 명령과 입력·기대 결과도 지정할 수 있습니다.
- **안정성 결과**: 호출 판정, 시간 초과·응답 불일치·컴파일/실행 오류, 정리 실패와 시간 변동·호출 P95·부하 처리량을 확인합니다.
- **그래프와 내보내기**: 앱에서 조건별 평균 시간과 유효 완료율을 전환합니다. TXT·CSV·Excel에 안정성 정보를 추가하고 SVG 그래프를 저장합니다.
- 그래프의 버전 순서·색을 기준 버전부터 고정하여 조건이나 지표를 바꿔도 일관되게 표시합니다. 기존 그래프 파일은 재실험 없이 새 사본으로 생성합니다.
- 연결 검색 실패를 빈 출력의 JSON 오류와 구분하고, 시행 상세에 호출 수·응답 검증 통과 수·첫 실패 순서를 표시합니다. 원문이 남아 있는 이전 기록에도 적용하며 실패 판정과 통계 제외 규칙은 유지합니다.
- **테마**: 설정 · 알림에서 연보라·로즈·민트 색면과 작은 구름 곡선의 색을 바꿉니다. 테마와 캐릭터 표시 선택은 다음 실행에도 복원합니다.

예정 시행 수, 실제 진행 단계·종료 시행 수·경과 시간을 제공하며 종료 후 선택 탭을 유지합니다. 조건별 시간·기준 버전 대비 비교·시행 상세는 그대로 제공합니다. 이전 기록도 읽으며 새 판정이 없는 필드는 추정하지 않습니다. CLI 측정·성공 판정·정리 규칙은 UI 개편으로 바꾸지 않았습니다.

자동 검사 222개를 통과했습니다. 앞선 Unity 6000.5.4f1·Bridge 0.2.1/0.2.3 연동 검사에서는 기본 연동 14개와 사용자 명령·오류 경로 8개 시행을 확인했습니다. 잘못된 C#에서는 CLI의 출력 인코딩 오류가 발생해 컴파일 오류 세부 분류 대신 CLI 종료 오류로 남는 한계가 확인되었습니다. 이번 UX·호환성 수정에서는 실제 Unity 벤치를 다시 실행하지 않았습니다. v0.1.3 실행 파일의 해시와 도움말 지원 옵션을 확인했으며 실제 명령 연동 성능 검증과는 구분합니다.

## 실행

1. Assets의 **UnityBridgeDesk-v0.4.0-win-x64.zip**을 받습니다.
2. 전체 압축을 풀고 **UnityBridge Desk 실행.exe**를 실행합니다. 옆의 app 폴더도 필요합니다.
3. 설치·활성화된 Unity와 비교할 릴리스 2개 이상을 선택합니다. 공식 Unity 비교를 켜면 UnityBridge 한 버전만 선택해도 됩니다.
4. 측정할 작업에서 F04 또는 S01을 선택하고 벤치를 시작합니다. 끝나면 결과 확인을 누릅니다.

.NET 런타임은 포함합니다. 가상머신·ISO·별도 계정은 필요하지 않습니다. GitHub가 자동 생성한 Source code ZIP에는 실행 파일이 없습니다.

## 해석 범위

S01은 요청 밀도를 높이는 시험이며 장시간 가동 시험이 아닙니다. 모든 내장 명령의 인수·선행 상태를 자동으로 만들지는 않습니다. 사용자 명령은 직접 지정한 시나리오로 시험하며, headless·새 최소 프로젝트에서 지원하지 않는 작업은 실패할 수 있습니다. 클라이언트 동시 요청 수가 Unity의 병렬 실행 수를 의미하지 않습니다.

완료율은 유효 시행 / 평가 대상 시행입니다. 환경 준비·벤치 호환성 오류, 사용자 중단·미수행은 평가 분모에서 제외하고 별도로 표시합니다. 정리 실패는 포함합니다. 작은 표본의 100%가 안정성을 보장하지 않습니다. 실패를 0ms로 합산하지 않으며 신뢰구간·전체 승자 판정은 제공하지 않습니다. Windows 계정·서비스·시스템 캐시는 공유합니다.
