Summary
Release v0.5.0: UI·UX 개편, 아라·아샤, 벤치 분석 방법론 통합

Description
v0.4.0 이후의 UI·UX와 캐릭터 후속 변경, 벤치마크 방법론을 v0.5.0 정식 배포로 통합한다.

- 좌측 탐색과 준비·진행·결과 흐름, 전체 조건 비교표·세로 그래프·시행 검색·필터, 선택·스크롤 복원과 설정 팝업을 포함한다.
- 파스텔 풍경 테마 3종과 일반 화면, 고양이 아라·여우 아샤의 개별 표시·행동 및 실제 UI 발판·낙하 계산을 포함한다.
- 시행 단위 평균과 쌍 시간비의 95% 신뢰구간, 예비 반복 설계·다음 실험 준비, 호출·시행 순서 그래프를 포함한다.
- 사전 실행 시간을 측정 평균과 분리하고, Excel 여덟 시트와 04_측정근거.txt에 수식·가정·반복 제안을 저장한다.
- 앱·Worker·실행기·배포 명세를 0.5.0으로 맞추고 README·릴리스 설명·검증 기록을 갱신한다.
- 기존 설정·결과 호환성을 유지한다. 리틀 모델 엔진은 별도 앱으로 유지한다.
