# UnityBridge Desk v0.3.1 · 벤치 중단 후 정리·복구 수정

벤치 중단 후 읽기 전용 UPM 임시 파일이 남아 다음 실행에서 `.local-owner.json`을 찾지 못하던 오류를 수정했습니다.

## 변경 사항

- 소유한 시험 폴더 안에서 읽기 전용 파일의 속성을 해제한 뒤 정리합니다.
- 내용부터 삭제하고 소유 정보는 마지막까지 보존합니다. 마지막 삭제 단계에서도 복구할 수 있도록 폴더 밖에 정리 기록을 남깁니다.
- 구버전에서 소유 정보가 유실된 폴더는 기존 요청·시행·경로·정리 실패 기록과 프로세스 종료를 확인한 경우에만 자동 복구합니다.
- 소유 근거가 없는 폴더는 보존하고 안내합니다. 설정·릴리스·결과를 초기화할 필요가 없습니다.
- 실험 명령·시간 측정 경계·결과 스키마는 유지합니다.

## 실행 및 업데이트

1. 기존 Desk 창을 닫습니다.
2. `UnityBridgeDesk-v0.3.1-win-x64.zip` 전체를 새 폴더에 압축 해제합니다.
3. 맨 위의 `UnityBridge Desk 실행.exe`를 실행합니다. 옆의 `app` 폴더도 함께 있어야 합니다.
4. 기존 설정을 확인한 뒤 벤치를 시작합니다. 이전 시험 폴더 복구는 새 벤치 시작 전에 자동으로 수행됩니다.

## 검증

- 자동 검사 178개 통과: Core 38 / Infrastructure 112 / Desktop 28.
- 읽기 전용 파일·삭제 잠금·소유 정보 유실·실행 중 프로세스·경로 불일치·정리 기록 복구 등 회귀 검사 8개 추가.
- 실제 발생한 잔여 폴더 복구와 기존 설정·릴리스·결과 351개 파일의 해시 보존 확인.
- 이번 수정에서 Unity 성능 측정은 다시 수행하지 않았습니다. 기존 18개 시행은 v0.3.0의 기능 확인 기록이며 버전별 속도 우열의 증거는 아닙니다.
