# GitHub Desktop Description

동일 C# 파일의 exec 첫 실행·준비 후 실행을 비교하는 F04와, UnityBridge 명령별 요청 수·동시 요청 수를 지정하는 S01을 추가한다.

기본 부하 시나리오 5종과 사용자 명령·JSON 입력·기대 결과를 지원한다. 호출별 성공·오류, 시행 완료율, 시간 변동·성공 호출 P95·부하 처리량을 기록한다. 시간 초과·응답 불일치 등에서는 새 요청 투입을 중지하고 이미 보낸 요청을 회수한다.

기존 결과 표와 메뉴를 유지하며 평균 시간·유효 완료율 그래프, Excel 안정성 시트, SVG 내보내기를 추가한다. 이전 기록의 누락된 판정은 추정하지 않는다. README와 측정 명세에 시간 경계·분모·설계 이유·지원 한계를 명시한다.

그래프의 버전 순서와 색을 기준 버전부터 고정하고, 조건 전환·측정값 누락에도 유지한다. SVG에도 동일한 기준을 적용하고 이전 보고서는 재실험 없이 새 형식의 사본으로 생성한다.

파스텔 배경·연보라·큰 시계를 보존하고 기존 마스코트를 그림자 없는 벡터로 표시한다. 고정 탭, 통일된 입력·메뉴, 간결한 우측 상태 영역으로 화면을 정리한다. 예정 시행 수와 실제 진행 단계·종료 수·경과 시간을 표시하고, 완료 시 사용자가 선택한 탭을 유지한다. 합성 WPF 화면으로 100·150·200% 배율, 작은 창, 드롭다운, 진행·실패·종료 상태를 확인한다.

CLI의 구조화된 표준 오류를 해석해 연결 검색 실패를 JSON 파싱 오류와 구분한다. 이전 기록의 오류 원문은 보존하고 읽기용 설명과 호출 수·첫 실패 순서를 개선한다. 보고서 형식 6을 새 사본으로 생성하며 실패 판정·속도 통계 제외 규칙은 유지한다.

연보라·로즈·민트의 색상과 전용 배경을 함께 전환한다. 로즈·민트는 기존 구름 역의 구도를 바탕으로 구름 형태를 변주한 내장 이미지다. 테마 저장을 벤치 작업 상태와 분리하고 연속 저장을 순서대로 처리해 마지막 선택과 재시작 복원을 보장한다.

Release 자동 검사 216개 통과. 앞선 Unity 6000.5.4f1·Bridge 0.2.1/0.2.3 연동에서 정상 연동 14개 및 사용자 명령·오류 경로 8개 시행을 확인했다. 실제 C# 문법 오류에서 CLI 출력 인코딩 오류가 관찰되어 CLI 종료 오류로 기록되는 한계를 문서화한다. 이번 오류 표시 수정에서는 실제 Unity 벤치를 다시 실행하지 않았다.
