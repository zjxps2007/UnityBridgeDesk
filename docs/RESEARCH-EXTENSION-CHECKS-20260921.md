# 연구 보완 검증 기록

2026-09-21. 실제 수행한 검사와 아직 확보하지 않은 연구 자료를 구분한다.

## 자동 검사와 화면 검토

Release 빌드는 경고·오류 없이 완료했다. Core 38, Infrastructure 209, Desktop 76, 총 **323개** 검사가 통과했다. VSTest 종료 진단에도 testhost의 처리되지 않은 종료 오류가 없었다.

조건 회차·버전 위치 균형과 시드 재현, 독립 시행 ID, DLL 변경에 따른 명세 변화, 개인 JSON 제외, F02 순서 무관·중복·개수·위치 오류, 전체 계획 분모, 과거 계획 호환성, 지연 대조의 내부·외부 구간과 누락 거부를 검사했다. F02 증거 ZIP은 변경된 파일을 거부하고 실패 관측을 보존한다.

실제 WPF에서 960×600·1440×850, 100·150% 연구 화면을 확인했다. 목적별 노출·질문/허용 차이의 오류 이동·숨겨진 값의 처리·설정 왕복·시작 조건을 검사했다. 작은 결과 화면에서 계획 전체 분모, 실패·미수행, 세션·묶음, 다음 행동과 새 세션 버튼을 확인했다. 기존 전체 화면 검사에는 100·150·200%·메뉴·키보드·스크롤·선택 유지도 포함된다. 디자인 근거와 아직 없는 사용자 과제 실험은 [UI·UX 기록](RESEARCH-UX-20260921.md)에 있다.

## 독립 재분석

앱에서 생성한 합성 자료 ZIP 3개를 외부 Python으로 검산했다. 원시 평균·쌍 구간과 Student 기준 수치가 일치했고, 파일 해시를 다시 계산해도 고정 계획의 설정을 바꾼 자료는 거부했다. 포함된 성공 F02 관측 3개를 별도 식으로 검사했으며 누락은 0이었다. 새 씬 파일이 ZIP 검산기의 허용 목록에 빠졌던 문제를 수정한 후 통과했다.

이는 계산·파일 관계·합성 정답 검사이다. 실제 Unity에서 반환한 관측 자료를 제삼자가 재현한 결과는 아니다.

## 실행기 진단

상대 저장 경로로 진단할 때 측정 실행기의 절대 경로 조건을 만족하지 못해 처리되지 않은 예외가 발생했다. 이 실패는 계측 자료로 사용하지 않았다. 자신이 시작한 실패 진단 프로세스만 종료했다. 경로를 절대 경로로 정규화하고 준비·프로세스 오류를 상태/종료 코드로 보고하도록 수정했다.

수정 후 같은 상대 경로 사용 방식으로 비Unity 자식 프로세스 60회를 완료했고 `diagnostic.json`과 읽기용 `00_진단요약.txt`를 확인했다. 테스트·빌드·모의실험과 동시에 실행하지 않았다. 이 진단은 프로세스 경로의 관찰이며 실제 Unity의 A/A·지연 대조나 정확성 인증이 아니다. 잔차를 벤치에서 빼지 않는다.

## 모의실험

8개 생성 조건에서 각각 1,000회, 총 8,000개 자료를 계산했다. 독립 조건 일부에서는 명목 95% 부근이었으나 자기상관·세션 군집에서는 올바른 유한 구간 비율이 52.2%·49.5%로 낮아졌다. 계획·분포·추정 대상·Monte Carlo 오차는 [모의실험 기록](RESEARCH-SIMULATION.md)에 공개한다. 현재 수식이 모든 환경에서 검증됐다는 주장을 하지 않는다.

## 남은 증거

실제 Unity A/A·100ms 지연 대조 실행, 예비 분포를 이용한 반복·워밍업 설계, 서로 다른 세션·장비, 실제 작업 대표성, 상관·다중 비교 분석, 외부 사전등록과 제삼자 재현이 남는다. 코드를 구현한 것과 이 자료들을 수집한 것을 혼동하지 않는다. 변경한 공통 fixture 해시를 보존하고 이전 fixture의 결과와 무조건 합치지 않는다.
